# Security

These skills are plain Markdown plus a few small scripts (`hookscore_ru.py`, `audio.py`, `render.mjs`). They need no keys and send no data anywhere. Read any skill before installing it.

To report a problem (a script doing something unexpected, a leaked secret, an unsafe instruction), open a private security advisory on this repository, or an issue if it is not sensitive. Please do not post keys or personal data in public issues.

Scope: the files in this repository. Third-party services (Anthropic, ElevenLabs, Instagram) are out of scope.
